# LAB06 — Waypoints

Proyecto Unity para el laboratorio de waypoints. Abrir la carpeta del proyecto desde Unity Hub con **Unity 6 `6000.3.17f1`**.

## Escenas

- `Assets/Scenes/TankRacing.unity`: escenario original de tanques y ruta de nueve waypoints.
- `Assets/Scenes/CarCircuit.unity`: ejercicio de carreras con autos, circuito costero y modo tracker.

En `CarCircuit`, pulsa **T** para cambiar entre seguimiento directo y tracker; pulsa **R** para reiniciar. El informe del laboratorio y las respuestas están en [`Assets/Documentation/LAB06_Waypoints.md`](Assets/Documentation/LAB06_Waypoints.md).
