# LAB06 — Waypoints

Proyecto Unity para el laboratorio de waypoints. Abrir la carpeta del proyecto desde Unity Hub con **Unity 6 `6000.3.17f1`**.

## Escenas

- `Assets/Scenes/TankRacing.unity`: escenario original de tanques y ruta de nueve waypoints.
- `Assets/Scenes/CarCircuit.unity`: circuito costero de autos; al abrirla, el contenido visible se genera y guarda en modo de edición, sin Play.

Ambas escenas incluyen un panel para cambiar entre tanques y autos y enfocar cada vehículo. En el circuito, el panel alterna seguimiento por waypoints/tracker y muestra vueltas; la pista, los autos y las barreras tienen colisionadores. El informe extenso, las respuestas y los espacios para capturas están en [`Assets/Documentation/LAB06_Waypoints.md`](Assets/Documentation/LAB06_Waypoints.md) y [`Assets/Documentation/Informe_Laboratorio_06_Waypoints.docx`](Assets/Documentation/Informe_Laboratorio_06_Waypoints.docx).
